# 📊 Sales Analysis Dashboard – Power BI

## 📌 Project Overview

This project focuses on analyzing sales performance using Microsoft Power BI. The objective is to transform raw data into meaningful business insights through an interactive dashboard.

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard creation and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Data Modeling** – Relationships between tables

## 📂 Dataset

The project uses three main tables:

- Sales
- Stores
- Customers

Product categories include Skincare, Haircare, Bodycare, Fragrance and Makeup.

## 📈 Key Performance Indicators

- Total Sales
- Sales by Product Category
- Sales by Region
- Sales by Store
- Sales Performance Over Time

## 🔍 Key Results

- Total sales analyzed: **292.682K TND**
- Sales performance evaluated across different stores and regions.
- Interactive visualizations developed to support business analysis.

Power BI · Data Analysis · Data Visualization · Power Query · DAX · Data Modeling
